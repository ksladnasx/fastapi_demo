FastAPI 认证学习演示

对比两种常见认证方式：前端保存 Token，以及后端通过 Set-Cookie 把 Cookie 写入浏览器。

学习重点

  1. Token 模式：登录接口返回 access_token，前端把它保存到 localStorage，并手动放进 Authorization 请求头。
  2. Cookie 模式：登录接口不要求前端保存 token，而是通过响应头 Set-Cookie 让浏览器自动保存 Cookie。
  3. 后续请求：前端 fetch 使用 credentials: "include"，浏览器会自动把 Cookie 带给后端。
  4. HttpOnly：会话 Cookie 不能被 JavaScript 读取，但可以在浏览器开发者工具的 Application / Cookies 中看到。
